# Loan Approval Prediction

## About the Project
This project explores applicant information and loan approval outcomes using Python and Machine Learning.

## Objectives
- Explore and understand a financial dataset.
- Identify input features and the target variable.
- Handle missing values and prepare data for analysis.
- Build a classification model to predict loan approval.
- Evaluate model performance.

## Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Project Progress
- [x] Dataset downloaded
- [x] Initial dataset exploration started
- [ ] Missing-value analysis and preprocessing
- [ ] Exploratory data analysis and visualizations
- [ ] Logistic Regression model
- [ ] Model evaluation

## Dataset
The project uses a publicly available loan prediction dataset available on kaggle. 

## Disclaimer
This project is for educational purposes. Predictions should not be used as the sole basis for real loan approval decisions.
